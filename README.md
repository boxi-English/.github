# Boxi English community health files

Boxi English builds open, inspectable resources for learning and using English.

The organization separates reusable learning code, public scenarios, public documentation, and private learner or course records. Contributions should state the learning objective, source provenance, feedback method, accessibility path, and content license.

Public repositories:

- [`english-explain`](https://github.com/boxi-English/english-explain) — learning primitives and lesson contract
- [`english-scenarios`](https://github.com/boxi-English/english-scenarios) — reproducible scenarios and practice fixtures
- [`english-site`](https://github.com/boxi-English/english-site) — public documentation and demos
